# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and constructive, assume good intent, criticize ideas rather than people, and make room
for newcomers. Harassment, insults and personal attacks are not tolerated in issues, pull requests,
discussions or any other project space.

## Reporting

Report unacceptable behavior to the maintainers at **CONDUCT_EMAIL**. Reports are kept confidential. The
maintainers decide on the response (a warning, a temporary or a permanent ban) following the Covenant's
enforcement guidelines.
